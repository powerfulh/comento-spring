REST API 문서 · v1

무료 띄어쓰기 교정 REST API

BETA

문장을 넣으면 띄어쓰기를 교정해 돌려줍니다. 인증 없이 바로 호출할 수 있습니다.

01 · 엔드포인트

요청

GET https://port-0-powerful-spring-boot-5o1j2llh1wq9rp.sel4.cloudtype.app/powerful/fix/space?pureSrc={텍스트}
파라미터타입설명
pureSrc필수 string 띄어쓰기를 교정할 원본 텍스트. URL 인코딩된 쿼리 파라미터로 전달합니다.

02 · 응답 형식

Response Body

result string 띄어쓰기가 교정된 전체 문장
s array 문장 내에서 이루어진 교정 지점들의 정보 배열

03 · 바로 테스트

직접 호출해보기

Enter로 문단 구분, 실제 서버로 요청이 전송됩니다.
